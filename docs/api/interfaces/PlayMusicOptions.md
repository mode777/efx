# Interface: PlayMusicOptions

Options for `audio.playBackgroundMusic`.

## Properties

### loop?

> `optional` **loop?**: `boolean`

Loop the track (default `false`).

***

### volume?

> `optional` **volume?**: `number`

Linear gain (default `1`); negative values are clamped to `0`.
