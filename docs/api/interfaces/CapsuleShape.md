# Interface: CapsuleShape

A vertical capsule collider.

## Properties

### height

> **height**: `number`

Total tip-to-tip height including caps; must be >= 2 * radius.

***

### radius

> **radius**: `number`

Capsule radius (must be > 0).

***

### type

> **type**: `"capsule"`

Discriminator selecting the capsule shape.
