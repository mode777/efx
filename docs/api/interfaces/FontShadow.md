# Interface: FontShadow

A baked blurred shadow behind glyphs.

## Properties

### blur

> **blur**: `number`

Blur radius in pixels (must be > 0).

***

### offset?

> `optional` **offset?**: [`Vec2`](../type-aliases/Vec2.md)

Pixel offset `[dx, dy]`; defaults to `[0, 0]`.
