# Interface: SourceRect

A `{ x, y, w, h }` rectangle in texture pixels.

## Properties

### h

> **h**: `number`

Height in texture pixels (must be > 0).

***

### w

> **w**: `number`

Width in texture pixels (must be > 0).

***

### x

> **x**: `number`

Left edge in texture pixels.

***

### y

> **y**: `number`

Top edge in texture pixels.
