# Interface: Camera3DOptions

Options for `setCamera3D`.

## Example

```js
efx.graphics.setCamera3D([0, 1.6, 4.2], [0, 0, 0], 60);
```

## Properties

### far?

> `optional` **far?**: `number`

Far plane distance (default 100).

***

### near?

> `optional` **near?**: `number`

Near plane distance (default 0.1).
