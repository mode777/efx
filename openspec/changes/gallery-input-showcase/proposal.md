# Proposal

**Roadmap position:** Cross-cutting showcase/tooling infrastructure — no
feature milestone. It adds curated gallery content that presents the
already-shipped F9 input API; it does not start or reopen a ladder
milestone. Precedent: the archived `gallery-asset-showcase` change
("Cross-cutting showcase/tooling infrastructure — no feature milestone").

## Why

F9 shipped a complete input layer (`efx.keyboard` / `efx.mouse` /
`efx.window`, queries plus unsubscribe-returning event callbacks), but the
only place it is exercised is headless tests. The gallery's other features
each have a visitor-facing showcase (a real texture, a real glTF model, a
rigged fox), while input — the thing a visitor must actually *do* — has
none. A visitor cannot see the query + event model, the surface-pixel
coordinate rule, or the high-DPI handling without reading the spec.

## What Changes

- **A curated input showcase sample.** `gallery/samples/curated/
  input-playground.js`: an interactive, self-playing particle playground
  that uses the whole F9 surface —
  - `efx.mouse.onMove` / `onDown` / `onWheel` event callbacks that paint
    trails, emit bursts, and change the brush;
  - `efx.keyboard.isPressed` one-shots (space burst, `c` clear, digit
    palette selection) and `efx.keyboard.isDown` held state (arrow/WASD
    movement, shift for a larger brush);
  - read-only `efx.mouse.position` / `delta` / `wheel`;
  - `efx.window.size` to map surface pixels to the fixed 2D camera frame,
    demonstrating the documented coordinate space.
- **An idle attract mode.** With no input the sample self-plays and shows
  a pulsing "click to interact" frame, so it looks alive in the gallery
  before the visitor focuses the iframe (the iframe focus requirement is
  a gallery/embedding concern, not an API change).
- **Manifest + catalog.** A `manifest.json` entry (category `Showcase`)
  and a regenerated `gallery/src/samples/generated.json`. No asset pack:
  the sample is fully procedural, so it needs no CC0 assets and no
  `CREDITS.md` change.

## Impact

- **Content:** `gallery/samples/curated/input-playground.js` (new),
  `gallery/samples/curated/manifest.json` (one entry). The catalog file
  `gallery/src/samples/generated.json` is gitignored and regenerated by
  `gen-catalog.mjs` at build time.
- **Docs:** `AGENTS.md` gallery bullet notes the input demo. No
  `docs/js-api.md` and no `gallery/src/api/efx.d.ts` change — the script
  API is unchanged (F9 already documented and typed).
- **Verification:** the sample is named `input-playground`, so its catalog
  id `curated:input-playground` sorts into the first eight samples the
  gallery smoke (`tools/run_gallery_smoke.mjs`) drives in headless Chrome;
  the smoke fails on any console/page error, exercising the new sample for
  free. No golden baselines change and no engine code changes.

## Non-goals

- No engine, renderer, or script-API change; no new `efx` function.
- No new golden scene — input has no visual gate (F9).
- No asset pack, no third-party assets, no `CREDITS.md` change.
- No gallery-shell change (the runner, catalog generation, and smoke are
  reused as-is); a click-to-focus affordance remains a gallery concern.
